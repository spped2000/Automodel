[Nemotron-3.5-Embed-8B-BF16](https://huggingface.co/nvidia/Nemotron-3.5-Embed-8B-BF16)
embeds text queries and documents containing an image, text, or both. It combines
a Pixtral vision encoder with the language model from
[Nemotron 3 Embed 8B](/model-coverage/embedding-models/nvidia/Nemotron-3-Embed-8B-BF16).

## Model Reference

### Model Architecture

| Property | Value |
| --- | --- |
| **Architecture** | `Mistral3Model` |
| AutoModel Backbone | `Mistral3BidirectionalModel` |
| Task | Multimodal embedding and dense retrieval |
| AutoModel Wrapper | `NeMoAutoModelBiEncoder` |
| Inputs | Text queries; image, text, or combined image-text documents |
| Embedding Dimensions | 4,096 |

## Fine-Tuning

The [8B multimodal embedding example](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/nemotron_3_5/embed_8b_multimodal.yaml)
trains the vision encoder and multimodal projector with a contrastive loss while
keeping the language model frozen. Follow the
[fine-tuning README](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/nemotron_3_5/README.md)
for the starting checkpoint, dataset format, dependencies, and launch command.

The example loads the released NVIDIA checkpoint and its processor directly.
No text and vision checkpoint assembly is needed for this fine-tuning workflow.
It adapts the existing model to your data; it does not reproduce the original
training stages, data mixture, or reported results.

The [model card](https://huggingface.co/nvidia/Nemotron-3.5-Embed-8B-BF16)
documents inference, processor settings, training data, and evaluation. For
second-stage relevance scoring, refer to
[Nemotron 3.5 Rerank 8B](/model-coverage/reranking-models/nvidia/Nemotron-3.5-Rerank-8B-BF16).
